# Service Mode

Keep farming after SSH closes — systemd user service.

## Install & start

```bash
tdm service install --user --autostart   # writes ~/.config/systemd/user/tdm.service
tdm service start
tdm service status
```

Equivalent manual:

```bash
systemctl --user daemon-reload
systemctl --user enable --now tdm.service
systemctl --user is-active tdm
```

## What `service install` writes

Template `resources/systemd/tdm.service.tpl`, generated by `src/ops/systemd.ts:generateUnitContents()`:

```ini
[Unit]
Description=Twitch Drops Miner CLI
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=<node> <tdm-bin> run
Restart=on-failure
RestartSec=5
NoNewPrivileges=true
PrivateTmp=true
Environment=TDM_LOG_LEVEL=info

[Install]
WantedBy=default.target
```

For monitoring, prefer `run --metrics-port 9098 --metrics-host 0.0.0.0` so health/metrics endpoints are live. Either edit the unit `ExecStart` or use an override:

```bash
systemctl --user edit tdm.service
# add:
# [Service]
# ExecStart=
# ExecStart=/usr/bin/node /path/to/dist/cli/index.js run --metrics-port 9098 --metrics-host 0.0.0.0
systemctl --user daemon-reload && systemctl --user restart tdm
```

## Logs

```bash
tdm logs --follow
# or
journalctl --user -u tdm.service -f
journalctl --user -u tdm.service -n 200 --no-pager
journalctl --user -u tdm.service --since "1 hour ago"
```

## Stop / restart / uninstall

```bash
tdm service stop
tdm service restart
tdm service status
tdm service uninstall --user   # disables + removes unit
```

## Metrics with the service

The homelab standard is port `9098` on `0.0.0.0` (so Glance/Prometheus can scrape):

```bash
curl -s http://127.0.0.1:9098/health  | jq   # watchingChannelLogin, watchingGame, minutesPerGame, pubsubConnected
curl -s http://127.0.0.1:9098/status  | jq   # + activeDrop, wantedGames, channelsCount, state
curl -s http://127.0.0.1:9098/drops   | jq   # [{game,name,progress,remaining,required,canClaim}]
curl -s http://127.0.0.1:9098/metrics | head # Prometheus twitch_drops_*
```

See [[Observability]] for the full metric list and Glance widget.

## System unit (requires root)

```bash
sudo tdm service install --system --autostart
sudo systemctl enable --now tdm.service
```

Not recommended for single-user — user units have least privilege and survive without root.

## Hardening

`NoNewPrivileges=true` + `PrivateTmp=true` + `Restart=on-failure` are baked in. For stricter lockdown see repo `docs/ops/systemd-hardening.md` ( `ProtectSystem=strict`, `ProtectHome=read-only`, etc. — only if state paths are allow-listed).

## Updating under a service

```bash
npm update -g twitchdropsminer-cli
tdm --version
systemctl --user restart tdm
tdm doctor --json | jq
```

`tdm-auto-update` (daily 06:00) — fetch → build → rsync `dist/` → `systemd-run` detached restart → health probes.
